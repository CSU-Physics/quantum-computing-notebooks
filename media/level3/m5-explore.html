How likely is a circuit to run without any error?

A circuit on n qubits with L layers. Each layer has one single-qubit gate on every qubit and a two-qubit gate on every pair of neighbours, n/2 of them; every qubit is measured at the end. The bars show P = (1 − e1)^n1 (1 − e2)^n2 (1 − e_ro)^nm with each device's published error rates (the same model as the lab). Grey rows have too few qubits.
