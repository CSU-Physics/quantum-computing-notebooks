Capstone: one experiment, done properly

Run an experiment on a noisy quantum computer, say how certain every number is, and say what it cannot show.

SemiAcademy · ISEP-CSUCC BY 4.0

By the end of this module you can

  • plan and run one experiment on a noisy simulator: error correction, mitigation, simulation or classification;
  • give every measured number with its uncertainty from the shots;
  • combine uncertainties, and decide with the 3σ rule whether a difference is real;
  • weigh bias against shot noise when you choose a method;
  • report the experiment: question, method, result, interpretation and limits.

The capstone brings course outcomes 2, 3 and 4 together: a code, a mitigation and an application, in one experiment.

Module 6 · Capstone4

The capstone noise model

  • Depolarizing error P2 after every two-qubit gate, P2/10 after every one-qubit gate.
  • Readout: a 0 is read as 1 with probability READOUT, a 1 as 0 with 2 · READOUT.
  • An idle error on id gates (repetition code only).
  • Course values P2 = 0.01, READOUT = 0.02: several times worse than IBM's best devices, so effects show in a few thousand shots.

Exact

exact_probabilities(): the noise model's probability of every result, from the density matrix. The value to compare with.

Sampled

sample_counts(): random shots drawn from those probabilities, as a quantum computer gives them.

Module 6 · Capstone5

Three formulas for the uncertainty of a result

What you measureStandard deviation from S shots
a fraction, true probability pσ = √( p (1 − p) / S )
an average of ±1 results, value Eσ = √( (1 − E²) / S )
a combination Σ cᵢ Eᵢ of independent resultsσ = √( Σ (cᵢ σᵢ)² )

Example: E = 0.8 from 4,000 shots has σ = √(0.36 / 4000) = 0.0095. The difference of two results has σdiff = √(σ₁² + σ₂²): uncertainties add in quadrature.

Module 6 · Capstone6

The 3σ rule

  • A measured value agrees with an expected one when they differ by at most 3σ.
  • A difference larger than 3σdiff is significant: shot noise alone almost never produces it.
  • A smaller difference may be real, but your data cannot show it. More shots shrink σ as 1/√S.

Two cautions

The rule assumes a bell-shaped spread, which holds when many shots give each result. And with many comparisons, a chance "significant" difference becomes likely somewhere: with 20 comparisons, about 5%. Test a surprise again with new shots.

Module 6 · Capstone7

Pause and predict

Zero-noise extrapolation combines three runs with weights 1.875, −1.25 and 0.375. Each run has σ of about 0.012 to 0.020. Is the extrapolated value more or less certain than a single run?

Less certain. With σ = 0.012, 0.015 and 0.020: √((1.875 · 0.012)² + (1.25 · 0.015)² + (0.375 · 0.020)²) = 0.030, about twice the σ of any single run. Large weights multiply the shot noise: removing bias costs certainty.
Module 6 · Capstone8

Repetition code: is the code worth it?

A memory experiment: encode 0, measure the syndrome for 1 to 5 rounds, decode by majority vote.

After 3 rounds the code's logical error is 0.0152 against 0.0340 for one qubit that waits as long.

Detection events (changes of the syndrome) are far more common than logical errors. Above P2 ≈ 0.037 the code stops helping: its break-even.

Module 6 · Capstone9

Mitigation study: removing bias step by step

⟨X X X⟩ of a GHZ state, ideally 1, under the course noise model; error bars for 4,000 shots per circuit.

Readout mitigation removes most of the bias; zero-noise extrapolation with global folding removes almost all of the rest.

Each step makes σ larger. ZNE alone, without the readout fix, reaches only 0.829: folding does not amplify readout errors.

Module 6 · Capstone10

Bias or shot noise: the shot budget

Root-mean-square error: RMS = √(bias² + σ²). σ shrinks as 1/√shots; the bias does not.

Few shots: readout mitigation alone is best. From about 3,200 shots in all, linear ZNE wins; quadratic ZNE only from about 2,000,000.

Module 6 · Capstone11

Spin chain: more steps, more noise

M(T = 2) for three spins, h = 0.7. Without noise, more Trotter steps are always better.

With noise, the raw value is best near 6 steps. Readout correction plus ZNE on the folded RZZ gates moves it close to the exact 0.386, and the best number of steps after mitigation is 6.

Module 6 · Capstone12

Pause and predict

The readout maps a true ⟨Z⟩ = z to (1 − 3r) z + r. At 8 Trotter steps the raw magnetization is about 0.33. How much will the readout correction change it?

Almost not at all. The map leaves z = 1/3 unchanged: (1 − 3r) · 1/3 + r = 1/3. M ≈ 0.33 sits next to this fixed point, so the correction moves it by about 0.0001. At t = 0, where M = 1, the same correction removes an error of 2r = 0.04.
Module 6 · Capstone13

Kernel classifier: noise the classifier ignores

60 overlap circuits of 1,000 shots: 28 for training, 32 for testing. Noise lowers every entry, and K(x, x) is about 0.90, not 1.

But noisy ≈ 0.85 · exact + 0.05: a straight line. Adding a constant and scaling (with C / a) leave the SVC's decisions unchanged.

Module 6 · Capstone14

Pause and predict

A classifier gets all 4 test points right. How often would a classifier that guesses at random do the same?

(1/2)⁴ = 0.0625, about one time in 16. An accuracy measured on 4 points also has σ = √(p (1 − p) / 4): 0.15 for p = 0.9. On all 20 test points of the data set the quantum kernel scores 0.90, with σ about 0.07.
