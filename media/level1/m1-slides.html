Why quantum computing?

A quantum computer is not a faster laptop. It processes information in a different way: superposition, interference and entanglement.

Simulating nature

Molecules and materials follow quantum rules: chemistry, batteries, medicines, new semiconductor materials.

Some math problems

Shor's algorithm would factor large numbers fast, once large error-corrected machines exist. That matters for encryption.

Open questions

Optimization and machine learning: active research, and the size of any advantage is not yet known.

For most everyday work, ordinary computers stay better and cheaper. Today's machines are noisy: they make errors.

Bits and qubits

Bit: always 0 or 1.

Qubit: a combination of two basis states.

|ψ⟩ = α|0⟩ + β|1⟩

α and β are amplitudes. They can be complex numbers.

Measuring a qubit always gives 0 or 1, never anything in between. The amplitudes decide how likely each result is.

Module 1 · From bits to qubits4

Not "secretly 0 or 1"

A common picture: a qubit in superposition is really 0 or 1, and we just do not know which.

That picture is wrong.
  • Probabilities are never negative, so they can only add up.
  • Amplitudes can be negative or complex, so they can cancel each other.
  • Module 3 shows an experiment where this cancellation (interference) gives a result no "secretly 0 or 1" model can explain.

Complex numbers in one minute

A complex number is a + bi, where i² = −1.

Its size squared is

|a + bi|² = a² + b²
  • |0.8i|² = 0.64
  • |−0.6|² = 0.36
  • |3 + 4i|² = 9 + 16 = 25

In Python, i is written 1j: abs(3+4j)**2 gives 25.0

The Born rule

The probability of each result is the size squared of its amplitude.

P(0) = |α|²    P(1) = |β|²

Example: the state [0.6, 0.8i]

  • P(0) = 0.6² = 0.36
  • P(1) = |0.8i|² = 0.64
  • Total: 0.36 + 0.64 = 1

The factor i changes the amplitude but not the probability. Module 2 shows when such phases do matter.

Measurement changes the state

  • One measurement gives one random bit, not the amplitudes.
  • To learn about a state, prepare it many times and measure each copy.
Module 1 · From bits to qubits9

Pause and predict

A qubit is in the state [0.8, −0.6].

What is P(1)? Does the minus sign matter?

P(1) = (−0.6)² = 0.36, and P(0) = 0.8² = 0.64. The minus sign does not change any probability. It changes the amplitude, which matters when amplitudes are combined (Module 3).
Module 1 · From bits to qubits10

Normalization

All probabilities must add up to 1, so a valid state needs

|α|² + |β|² = 1   ⇔   length √(|α|² + |β|²) = 1

Any nonzero vector becomes a valid state if you divide every amplitude by the length. The ratio between the amplitudes stays the same.

Worked example

[3, 4i] has length √(9 + 16) = 5.
Divide by 5: [0.6, 0.8i].

In NumPy

state / np.linalg.norm(state)

Pause and predict

Is [0.5, 0.5] a valid qubit state? If not, normalize it.

No: 0.25 + 0.25 = 0.5, not 1. Its length is √0.5 ≈ 0.707. Dividing by it gives [0.707, 0.707], which is the state |+⟩.

More qubits, many more amplitudes

n qubits have 2ⁿ basis states, so the state vector has 2ⁿ amplitudes.

Qubits nBasis statesAmplitudes
1|0⟩, |1⟩2
2|00⟩, |01⟩, |10⟩, |11⟩4
3|000⟩ … |111⟩8
50about 1.1 × 10¹⁵

At 16 bytes per complex amplitude, a 50-qubit state needs about 18 petabytes of memory. That is why large quantum states are so hard to simulate on ordinary computers.

Shots and statistics

A quantum computer runs the same circuit many times and counts the results. Each run is a shot.

With N shots and probability p of getting 1:

Expected count

N · p

Typical spread

√(N · p · (1 − p))

Almost always

within 3 spreads of N · p

Module 1 · From bits to qubits14

What 1,000 shots of [0.6, 0.8i] look like

  • Expected: 1000 × 0.64 = 640
  • Spread: √(1000 × 0.64 × 0.36) ≈ 15
  • 655 is normal.
  • 700 is four spreads away: something is different.

Pause and predict

You measure |+⟩ 400 times.

About how many 1s do you expect, and how much will the count vary?

Expected: 400 × 0.5 = 200. Spread: √(400 × 0.5 × 0.5) = 10. Most counts fall between about 190 and 210, and almost all between 170 and 230.

Summary

  • A qubit state is a vector of two amplitudes, [α, β].
  • Born rule: P(0) = |α|², P(1) = |β|².
  • Valid states have length 1; normalize by dividing by the length.
  • Measurement gives 0 or 1 and leaves the qubit in that state.
  • N shots: about N·p ones, give or take √(N·p·(1 − p)).
