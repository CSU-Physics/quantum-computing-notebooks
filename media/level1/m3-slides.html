Single-qubit gates

Gates as matrices and as turns of the Bloch sphere: X, Y, Z, H, S, T and the rotation gates, why every gate can be undone, and how phases interfere.

  • describe each gate as a turn of the Bloch sphere, and use the rotation gates Rx, Ry and Rz;

This is the first half of course outcome 2: write single- and two-qubit gates as matrices and verify them in code. Module 4 adds two qubits.

Module 3 · Single-qubit gates2

A gate is a matrix

A one-qubit state is a column of two amplitudes. A one-qubit gate is a 2 × 2 matrix U, and applying it is a matrix product:

new state = U · state

The X gate swaps the two amplitudes:

X = [[0, 1], [1, 0]],   X·[α, β] = [β, α]

So X|0⟩ = |1⟩ and X|1⟩ = |0⟩: the quantum NOT gate.

In Qiskit and qsim: qc.x(0). Operator(qc) gives the matrix of a whole circuit.

The Pauli gates: half turns

GateMatrix|0⟩ becomes|1⟩ becomesOn the Bloch sphere
X[[0, 1], [1, 0]]|1⟩|0⟩half turn about x
Y[[0, −i], [i, 0]]i|1⟩−i|0⟩half turn about y
Z[[1, 0], [0, −1]]|0⟩−|1⟩half turn about z

Z leaves |0⟩ and |1⟩ in place (the minus sign on |1⟩ alone is a global phase), but it flips the relative phase: Z|+⟩ = |−⟩.

Module 3 · Single-qubit gates4

The Hadamard gate H

H = (1/√2)·[[1, 1], [1, −1]]
  • H|0⟩ = |+⟩ and H|1⟩ = |−⟩: it makes equal superpositions.
  • H|+⟩ = |0⟩ and H|−⟩ = |1⟩: it also undoes them.
  • On the sphere: a half turn about the axis halfway between x and z, so it swaps the x and z axes.

That swap is why measuring in the X basis is "H, then measure in Z" (Module 2).

Module 3 · Single-qubit gates5

Phase gates S and T: turns about z

S = [[1, 0], [0, i]]
T = [[1, 0], [0, eiπ/4]]
  • Only the phase of |1⟩ changes, so P(0) and P(1) never change.
  • S is a quarter turn about z (90°), T an eighth turn (45°).
  • So T·T = S and S·S = Z, and eight T gates make a full turn.
  • Their inverses S† and T† turn the other way.
Module 3 · Single-qubit gates6

Pause and predict

Start in |+⟩. Apply S. Then apply S again. Where is the state after each step, and what are P(0) and P(1) at the end?

After one S: |+i⟩ (a quarter turn from +x to +y). After two: |−⟩, because S·S = Z and Z|+⟩ = |−⟩. P(0) = P(1) = ½ the whole time: phase gates move the arrow around the equator, never up or down. Only a measurement in another basis, or interference, shows the change.
Module 3 · Single-qubit gates7

Every gate can be undone

Gate matrices are unitary:

U† U = I

U† ("U-dagger") is the conjugate transpose. It undoes U, so no information is lost. Unitary matrices also keep the total probability at 1.

  • X, Y, Z and H are their own inverses: H·H = I.
  • S† = [[1, 0], [0, −i]] undoes S; T† undoes T.

Not reversible

A measurement is not a gate. It picks one result and the rest of the state is gone, so it cannot be undone.

Module 3 · Single-qubit gates8

Undoing a sequence of gates

Run the inverse gates in reverse order: to undo "A then B", undo B first, then A, like taking off shoes before socks.

Every shot then gives 0. In the lab, Step 7 has a version of this circuit with one wrong gate for you to find.

Module 3 · Single-qubit gates9

Rotation gates Rx, Ry, Rz

Turn the arrow by any angle θ about the x, y or z axis:

R(θ) = cos(θ/2)·I − i sin(θ/2)·P

where P is X, Y or Z for the axis. For example

Ry(θ) = [[cos θ/2, −sin θ/2], [sin θ/2, cos θ/2]]

The matrix uses θ/2: a turn of θ on the sphere is half that in amplitude space, as with cos(θ/2) in Module 2.

Module 3 · Single-qubit gates10

Rz and the phase gate: the same turn

Rz(φ) = [[e−iφ/2, 0], [0, eiφ/2]]
P(φ) = [[1, 0], [0, eiφ]] = eiφ/2·Rz(φ)

They differ by a global phase, so they are the same gate as far as any measurement can tell. For example Rz(π) = −i·Z.

In code

Operator(rz) == Operator(z): False, the matrices differ.

Operator(rz).equiv(z): True, equal up to a global phase.

Every gate is a turn of the Bloch sphere

GateTurnThe same as (up to a global phase)
X, Y, Z180° about x, y, zRx(π), Ry(π), Rz(π)
S, S†90° about z, either wayRz(π/2), Rz(−π/2)
T, T†45° about z, either wayRz(π/4), Rz(−π/4)
H180° about the axis halfway between x and zRy(π/2) then X

Any single-qubit gate turns the sphere about some axis by some angle. That is why the Bloch sphere is such a useful picture for one qubit.

Module 3 · Single-qubit gates12

Pause and predict

Start in |0⟩. Apply Ry(π/2), then Rz(π/2). Where does the arrow end, and what is P(0) in the Z basis?

Ry(π/2) turns the arrow from the north pole down to +x: the state |+⟩. Rz(π/2) then turns it a quarter turn about z, from +x to +y: the state |+i⟩ (up to a global phase). P(0) = (1 + z)/2 = ½, because the arrow is on the equator.
Module 3 · Single-qubit gates13

Gates in sequence: order matters

For the circuit H then S, H acts first, so its matrix goes on the right:

U = S · H

With gates G1, …, Gk in time order:

U = Gk ··· G2 · G1

Matrices do not commute: S·H ≠ H·S.

Two useful identities

H · Z · H = X
H · X · H = Z

H swaps the roles of x and z, so it turns a Z turn into an X turn and back.

Module 3 · Single-qubit gates14

Interference: H, phase, H

After H: (|0⟩ + |1⟩)/√2. After P(φ): (|0⟩ + eiφ|1⟩)/√2. After the second H, the amplitude of 0 is (1 + eiφ)/2: the two paths add for φ = 0 and cancel for φ = π.

Module 3 · Single-qubit gates15

The same story on the Bloch sphere

  1. H takes |0⟩ to +x.
  2. P(φ) turns the arrow by φ around the equator.
  3. H swaps x and z, so the x coordinate cos φ becomes the z coordinate.
P(0) = (1 + cos φ)/2 = cos²(φ/2)

Without the second H, P(0) stays ½ for every φ: the phase is there, but nothing turns it into a different probability.

Module 3 · Single-qubit gates16

Pause and predict

The circuit is H, then T, then H, then a measurement. What fraction of shots give 0?

T is the phase gate with φ = π/4. So P(0) = cos²(π/8) ≈ 0.854: about 854 zeros in 1,000 shots. With S (φ = π/2) it would be ½, and with Z (φ = π) it would be 0: every shot gives 1.

Summary

  • A gate is a unitary 2 × 2 matrix: a turn of the Bloch sphere.
  • X, Y, Z: half turns. H swaps x and z. S, T: 90° and 45° about z.
  • Rx, Ry, Rz turn by any angle θ; the matrix uses θ/2.
  • U† undoes U; undo a sequence in reverse order.
  • The first gate's matrix goes on the right. H, phase, H gives P(0) = cos²(φ/2).
