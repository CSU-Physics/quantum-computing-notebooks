Module 2 · One qubit2

Kets and bras

A ket is a column of amplitudes:

|ψ⟩ = α|0⟩ + β|1⟩ = [α, β]

Its bra is the row of complex conjugates:

⟨ψ| = [α*, β*]

The conjugate flips the sign of the imaginary part: (0.8i)* = −0.8i.

KetVector
|0⟩[1, 0]
|1⟩[0, 1]
|+⟩[1, 1]/√2
|−⟩[1, −1]/√2
|+i⟩[1, i]/√2
|−i⟩[1, −i]/√2
Module 2 · One qubit3

The inner product ⟨φ|ψ⟩

Multiply the bra of φ by the ket of ψ, entry by entry, and add:

⟨φ|ψ⟩ = φ₀* ψ₀ + φ₁* ψ₁

Basis states

⟨0|0⟩ = ⟨1|1⟩ = 1 (length 1)
⟨0|1⟩ = 0 (orthogonal)
Together: an orthonormal basis.

Worked example

ψ = [0.6, 0.8i]
⟨+|ψ⟩ = (0.6 + 0.8i)/√2
|⟨+|ψ⟩|² = (0.36 + 0.64)/2 = 0.5

In NumPy: np.vdot(phi, psi) conjugates the first argument for you.

Probabilities in any basis

For any orthonormal basis {|b₀⟩, |b₁⟩}, measuring in that basis gives

P(bk) = |⟨bk|ψ⟩|²
BasisBasis statesName
Z|0⟩, |1⟩the computational (standard) basis
X|+⟩, |−⟩the Hadamard basis
Y|+i⟩, |−i⟩the circular basis

Module 1's rule P(0) = |α|² is the Z-basis case: α = ⟨0|ψ⟩.

Module 2 · One qubit5

Global phase: no physical effect

Multiply the whole state by a phase eiγ:

|⟨b|eiγψ⟩|² = |eiγ|² |⟨b|ψ⟩|² = |⟨b|ψ⟩|²
  • Every probability, in every basis, stays the same.
  • So eiγ|ψ⟩ and |ψ⟩ are the same physical state: −|1⟩ is |1⟩, and i|+⟩ is |+⟩.
  • We can always choose the phase so that the amplitude of |0⟩ is real and not negative.
Module 2 · One qubit6

Pause and predict

Are these pairs the same physical state?

  1. (|0⟩ + |1⟩)/√2 and (−|0⟩ − |1⟩)/√2
  2. (|0⟩ + |1⟩)/√2 and (|0⟩ − |1⟩)/√2
1. Yes: the second is the first times −1, a global phase. 2. No: only the sign of |1⟩ changed. That is a relative phase. Both give 50/50 in the Z basis, but in the X basis |+⟩ always gives + and |−⟩ always gives −.
Module 2 · One qubit7

Two angles describe any pure state

Up to a global phase, every state can be written

|ψ⟩ = cos(θ/2)|0⟩ + eiφ sin(θ/2)|1⟩
  • θ, from 0 to π: how far from |0⟩ toward |1⟩;
  • φ, from 0 to 2π: the relative phase, the angle around the equator.

The point with these angles is the state's place on the Bloch sphere.

Worked example: [0.6, 0.8i]

a* b = 0.6 × 0.8i = 0.48i, so x = 0, y = 0.96, z = 0.36 − 0.64 = −0.28.
θ ≈ 106°, φ = 90°: nearly on +y, a little below the equator.

Module 2 · One qubit10

Pause and predict

Where on the Bloch sphere is (|0⟩ − i|1⟩)/√2? What are θ and φ?

a = 1/√2, b = −i/√2, so a* b = −i/2: x = 0, y = −1, z = 0. It is the point −y, the state |−i⟩, with θ = π/2 and φ = 3π/2 (because ei3π/2 = −i).
Module 2 · One qubit11

Relative phase: same Z results, different states

|+⟩, |+i⟩, |−⟩ and |−i⟩ all have θ = π/2, so each gives 0 or 1 with probability ½ in the Z basis.

They differ only in φ, the relative phase, and sit at four different points on the equator.

A Z measurement cannot tell them apart. A measurement in the X or Y basis can, and so can interference (Module 3).

Module 2 · One qubit12

Measuring in the Z, X and Y bases

Each basis is an axis of the sphere. The probability of the + end of that axis is set by the arrow's coordinate along it:

Z basis

P(0) = (1 + z)/2

X basis

P(+) = (1 + x)/2

Y basis

P(+i) = (1 + y)/2

After the measurement the qubit is in the basis state that was found, so measuring again in the same basis gives the same result.

Module 2 · One qubit13

On a quantum computer: rotate, then measure

In the circuit model used here, the readout measures in the Z basis. To measure in another basis, first rotate that basis onto Z:

In code: qc.h(0); qc.sdg(0); qc.h(0); then qc.measure(0, 0). The order matters: S† first.

Module 2 · One qubit15

Pause and predict

You prepare |+i⟩ and measure it 1,000 times in the X basis, then 1,000 times in the Y basis. What do you expect?

|+i⟩ is the point +y, so x = 0 and y = 1. X basis: P(+) = (1 + 0)/2 = ½, about 500 of each result. Y basis: P(+i) = (1 + 1)/2 = 1, every shot gives +i (result 0).
Module 2 · One qubit16

Finding a state from counts: tomography

Turn the rule around. If a fraction f of shots gives 0 in a basis, estimate that coordinate as

x̂ = 2f − 1

Do it in X, Y and Z to locate the arrow. Each estimate's standard deviation is √((1 − x²)/N), at most about 0.032 for 1,000 shots.

Three bases are needed: Z alone misses the phase. Raw estimates can land just outside the sphere (this one has length 1.0004), and near the poles φ is poorly determined.

Module 2 · One qubit17

Summary

  • Kets are columns, bras are conjugated rows; P(b) = |⟨b|ψ⟩|² in any basis.
  • A global phase changes nothing; a relative phase is a different state.
  • Every state is a point (θ, φ) on the Bloch sphere; opposite points are orthogonal.
  • P(0) = (1 + z)/2, P(+) = (1 + x)/2, P(+i) = (1 + y)/2.
  • Measure in X with H, in Y with S† then H, before the Z measurement.
