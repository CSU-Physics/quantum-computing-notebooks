How far can a correct run land from the expected value?

Each run takes S shots of a circuit whose result comes out with probability p, and records the fraction f. Run it many times: the fractions scatter around p with standard deviation σ = √(p(1 − p)/S). The shaded band is p ± 3σ, the course's rule for agreement.

Is a difference real, or shot noise?

Two circuits succeed with probabilities p₁ and p₂. Each experiment runs both with S shots and tests the measured difference against 3σdiff, σdiff = √(f₁(1 − f₁)/S + f₂(1 − f₂)/S). How often does an experiment detect the real difference?
