A measurement in the middle of a circuit

q_0: ─[H]──[H]──[M]──
c: 1/══════════════0══

H·H = I: the two paths to |1⟩ cancel. 1,000 of 1,000 shots give 0.

q_0: ─[H]──[M]──[H]──[M]──
c: 2/═══════0═════════1═══

The middle measurement leaves |0⟩ or |1⟩, not |+⟩. The second H makes a new superposition.

Module 0 · Dynamic circuits and teleportation5

Pause and predict

A qubit starts in |0⟩. The circuit is H, measure into c0, H, H, measure into c1. In what fraction of shots is c1 different from c0?

None. After the middle measurement the qubit is |0⟩ or |1⟩, matching c0, and H·H = I leaves it there. So 00 and 11 each come up about half the time, and 01 and 10 never appear.
Module 0 · Dynamic circuits and teleportation6

Classical feedforward

A dynamic circuit uses a measurement result during the circuit to choose the next gates. In Qiskit 2, and in qsim, this is a block:

qc.measure(0, 0)
with qc.if_test((0, 1)):    # only in shots where c0 == 1
    qc.x(0)
  • The gates inside run only in the shots where the bit has that value.
  • An else block is possible too: with qc.if_test((0, 1)) as else_: ... with else_: ...
  • qsim's drawer shows the block as a box, [IF c0=1]; these slides also write the gate inside it: [IF c0=1: X].
Module 0 · Dynamic circuits and teleportation7

An active reset

q_0: ─[RY(θ)]──[M]──[IF c0=1: X]──[M]──
c: 2/═══════════0══════════════════1═══
  • Measure: the qubit is now |0⟩ (c0 = 0) or |1⟩ (c0 = 1).
  • If c0 = 1, apply X: |1⟩ becomes |0⟩.
  • Either way the qubit ends in |0⟩, so c1 = 0 in every shot.

Why it is useful

Real computers reuse qubits within one circuit. Waiting for a qubit to relax to |0⟩ by itself is slow; measure-and-flip is fast. You write this as active_reset() in the lab.

Where feedforward is used

Teleportation

Two measured bits choose Bob's corrections. This module.

Phase estimation

Iterative phase estimation reuses one qubit: it measures a bit, then adjusts the next rotation. Module 1.

Error correction

Measured syndromes choose which qubit to fix, while the computation continues. Level 3.

IBM's current processors run dynamic circuits: the control electronics read the measurement and choose the next gates while the circuit is still running, before the other qubits lose their state.

Module 0 · Dynamic circuits and teleportation9

The problem teleportation solves

Alice holds a qubit in a state |ψ⟩ = α|0⟩ + β|1⟩ that she does not know. Bob is somewhere else. Only classical bits can travel between them.

  • Measure and send the result? One measurement gives one bit and destroys α and β.
  • Copy the qubit? Impossible: the no-cloning theorem says no circuit copies an unknown state.
  • Teleport it. Use one shared Bell pair and send two classical bits. The state appears at Bob's qubit and is destroyed at Alice's, so nothing is copied.

What Bob holds after Alice measures

After step 2 the three-qubit state can be rewritten as four equal terms, one for each of Alice's results:

½ Σ |c1 c0⟩ ⊗ Xc1 Zc0 |ψ⟩
Alice's result (c1 c0)probabilityBob's qubitBob applies
001/4α|0⟩ + β|1⟩ = |ψ⟩nothing
011/4α|0⟩ − β|1⟩ = Z|ψ⟩Z
101/4β|0⟩ + α|1⟩ = X|ψ⟩X
111/4−β|0⟩ + α|1⟩ = XZ|ψ⟩X, then Z

The probabilities are 1/4 whatever α and β are: Alice's results say nothing about |ψ⟩.

Module 0 · Dynamic circuits and teleportation12

Bob's corrections

Each error is undone by the same gate, because X·X = I and Z·Z = I. The order matters for result 11: the last error made is undone first.

with qc.if_test((1, 1)):    # c1 == 1
    qc.x(2)
with qc.if_test((0, 1)):    # c0 == 1
    qc.z(2)

Check for 11: Z·X·(X·Z|ψ⟩) = Z·Z|ψ⟩ = |ψ⟩.

Which bit controls which gate?

c1 comes from Alice's half of the Bell pair: it controls X. c0 comes from the qubit that held |ψ⟩: it controls Z. Mixing them up is the most common mistake, and the lab's check cell catches it.

Module 0 · Dynamic circuits and teleportation13

Pause and predict

Alice's result is 01. Bob mixes up the two bits and applies X instead of Z. What does he hold?

X·Z|ψ⟩ = −β|0⟩ + α|1⟩, which is not |ψ⟩ (unless the state is special). On the Bloch sphere, Z then X is a half turn about the y axis: (x, y, z) becomes (−x, y, −z). The fidelity with |ψ⟩ is y², where y is the Bloch y component: 0 for every state with real α and β, such as ry(θ)|0⟩.
Module 0 · Dynamic circuits and teleportation14

Bob learns nothing until the bits arrive

Before Alice's bits reach him, Bob does not know which of the four states he holds. Each has probability 1/4, and the four Bloch vectors add up to zero:

ρBob = ¼(ψ + ZψZ + XψX + XZψZX) = I/2

That is the completely mixed state, Bloch vector (0, 0, 0), for every |ψ⟩. So no information travels until the classical bits do, and they travel no faster than light.

Module 0 · Dynamic circuits and teleportation15

Checking that the state arrived

In a simulator

Take Bob's qubit out of the three-qubit density matrix with partial_trace and compare it with |ψ⟩: the fidelity is 1.000000 and the Bloch vectors are equal.

On real hardware: the undo test

The state cannot be looked at. Instead Bob applies the inverse of Alice's preparation and measures. If |ψ⟩ arrived, he gets 0 in every shot: 1,000 of 1,000 in the simulator.

On a noisy computer the undo test gives fewer zeros. The fraction of zeros is a simple measure of how well teleportation worked. Module 4 runs circuits like this with a realistic noise model.

Summary

  • A measurement in the middle of a circuit gives a usable bit and leaves |0⟩ or |1⟩: interference after it is lost.
  • qc.if_test((clbit, value)) runs gates only in matching shots. Measure plus feedforward rebuilds a reset.
  • Teleportation: Bell pair, Alice's Bell measurement, then X if c1 = 1 and Z if c0 = 1.
  • Each of Alice's results has probability 1/4, and Bob's qubit is I/2 until the bits arrive.
  • Check with the fidelity in a simulator, or with the undo test on hardware.
