Shor's algorithm and period finding

Factoring reduces to finding a period. Phase estimation finds it, continued fractions read it, and a few gcds finish the job.

Module 3 · Shor's algorithm2

Why factoring matters

RSA encryption and signatures are safe only if nobody can factor the public modulus N, a product of two large primes (2,048 bits is common).

The best known classical algorithms take time that grows faster than any power of the number of digits. Shor's algorithm (1994) needs time that grows only like a power: polynomial time on a large fault-tolerant quantum computer.

The plan

1. Pick a random a.
2. Find its order r (quantum).
3. Get factors with gcds (classical).
4. If it fails, pick another a.

The order of a mod N

For a with no factor in common with N, the powers a, a², a³, ... mod N repeat. The order r is the smallest r > 0 with

ar mod N = 1
k123456
7k mod 157413174

So the order of 7 mod 15 is r = 4. Classical search needs about r steps, and r can be nearly as large as N.

Module 3 · Shor's algorithm4

From the order to the factors

If r is even, let h = ar/2 mod N. Then h² mod N = 1, so

(h − 1)(h + 1) is a multiple of N

If also h ≠ N − 1, neither factor is a multiple of N, so each shares a factor with N: gcd(h − 1, N) and gcd(h + 1, N).

a = 7, N = 15, r = 4: h = 7² mod 15 = 4, gcd(3, 15) = 3 and gcd(5, 15) = 5. If r is odd or h = N − 1, try another a; for N with two or more different odd prime factors, at least half of the possible a work.

Pause and predict

N = 15. What do a = 2 and a = 14 give?

a = 2: the powers are 2, 4, 8, 1, so r = 4 and h = 2² = 4: gcd(3, 15) = 3 and gcd(5, 15) = 5. a = 14: 14² = 196 = 13·15 + 1, so r = 2, but h = 14 = N − 1, and the gcds are the useless 15 and 1. Pick another a.
Module 3 · Shor's algorithm6

The quantum step: a phase estimation

Let U multiply a register by a mod N: U|x⟩ = |a·x mod N⟩. Since ar = 1 mod N, Ur = I, so every eigenvalue is e2πi·s/r.

  • Eigenvectors: |us⟩ = (1/√r) Σk e−2πi·sk/r |ak mod N⟩, with eigenphase s/r, for s = 0, ..., r − 1.
  • We cannot prepare one |us⟩ without knowing r, but their equal superposition is easy: (1/√r) Σs |us⟩ = |1⟩.
  • Phase estimation started on |1⟩ returns m/2ᵗ ≈ s/r for a random s.

A prepared circuit, hard-coded for N = 15

The lab's c_amod15(a, power) multiplies by a mod 15 with a fixed pattern of controlled swaps (cswap) and controlled X gates, one pattern for each a in 2, 4, 7, 8, 11, 13.

It is not a general method. For a real N, modular multiplication is built from quantum adders using only a and N, and that arithmetic, run with error correction, is the main cost of Shor's algorithm.

a = 7

controlled swaps of register bits (0, 1), (1, 2) and (2, 3), then a controlled X on each register bit: x becomes 7x mod 15.

Pause and predict

N = 15, a = 7, and your first shot gives m = 128 with 8 counting qubits. What do you conclude, and what do you do next?

128/256 = 1/2, so the candidate is r = 2. But 7² mod 15 = 4, not 1, so 2 is not the order: here s = 2 and r = 4 share a factor. Take another shot; m = 64 or 192 gives 1/4 or 3/4 and the order 4. (You can also take the least common multiple of the denominators from several shots.)

What it would take to break RSA-2048

  • Shor's algorithm needs over a thousand error-corrected (logical) qubits and billions of gate operations, and each logical qubit is built from many physical qubits.
  • A 2025 estimate by Craig Gidney (Google): under one million noisy physical qubits, running for under a week, assuming a 0.1% error rate and a 1 µs error-correction cycle. In 2019 the estimate was 20 million qubits for 8 hours.
  • No quantum computer today comes close; the 15 = 3 × 5 of this lab is a demonstration.

Source: arXiv:2505.15917 (2025); Gidney and Ekerå, Quantum 5, 433 (2021).

Post-quantum cryptography

New standards

NIST published FIPS 203 (ML-KEM, key exchange), FIPS 204 (ML-DSA, signatures) and FIPS 205 (SLH-DSA, signatures) on 13 August 2024. They run on ordinary computers.

More coming

FIPS 206 (FN-DSA, from Falcon) is in development, and HQC was selected on 11 March 2025 as a backup key-exchange method.

Transition

NIST's draft plan (IR 8547, 2024) would disallow RSA and elliptic-curve methods after 2035, with the weakest key sizes deprecated after 2030.

"Harvest now, decrypt later": data recorded today could be read once a large quantum computer exists, which is why the move starts now.

Module 3 · Shor's algorithm15

What Shor's algorithm does not break

  • Shor's algorithm breaks public-key methods built on factoring and discrete logarithms: RSA, Diffie-Hellman and elliptic-curve cryptography.
  • Symmetric ciphers such as AES face only Grover's search (Module 2): a quadratic speed-up, so a 256-bit key keeps a large security margin.
  • The post-quantum standards are built on other mathematical problems (lattices, hash functions, codes) for which no fast quantum algorithm is known.

Summary

  • Order r: smallest r with ar mod N = 1. Even r and ar/2 ≠ −1 give the factors gcd(ar/2 ± 1, N).
  • Order finding is phase estimation of "multiply by a mod N", started in |1⟩: each shot gives m/2ᵗ ≈ s/r.
  • Continued fractions give s/r; check the denominator, and use another shot if s shares a factor with r.
  • The N = 15 circuit is prepared; real modular arithmetic with error correction is the hard part. Post-quantum standards replace RSA.
