Module 6 · A first quantum algorithm2

The query model

A function f is hidden in a black box. You cannot look inside; you can only ask it questions: give it x, get f(x).

The cost of an algorithm is the number of queries. Everything else is free.

An idealized model, but a clean place to compare classical and quantum algorithms. The ideas behind Shor's factoring algorithm were first found in this setting.

The Bernstein-Vazirani problem

The box hides an n-bit string s and answers

f(x) = s·x mod 2

the parity of the positions where both s and x have a 1. Find s.

The classical answer: n queries

Ask about inputs with a single 1. The input with a 1 in position j answers with that bit of s:

f(100) = 1,   f(010) = 0,   f(001) = 1  →  s = 101

That takes n queries. No classical method can do better: each answer is a single bit, and s has n unknown bits.

In the lab

classical_bv(query, n) asks the n questions and joins the answers into s.

An 8-bit string takes 8 queries.

Pause and predict

The hidden string has 20 bits. How many queries does a classical computer need to be sure of s? Could a clever choice of inputs, such as x = 111…1, do better?

20. Any input, clever or not, returns one bit, so 19 answers leave at least two possible strings. x = 111…1 returns the parity of all of s: useful, but still only one bit.
Module 6 · A first quantum algorithm6

The oracle as a circuit

The quantum box acts on n input qubits and one answer qubit:

|x⟩|y⟩ → |x⟩|y ⊕ f(x)⟩

For f(x) = s·x mod 2: one CNOT from each input qubit where s has a 1 to the answer qubit. Each adds xi; together they add the parity.

Character s[n − 1 − i] belongs to qubit i.

Module 6 · A first quantum algorithm7

Phase kickback

Put the answer qubit in |−⟩ first. Flipping |−⟩ gives −|−⟩: the qubit does not change, but the state picks up a sign.

|x⟩|−⟩ → (−1)f(x) |x⟩|−⟩

The answer moves from the answer qubit into the phase of the input. A CNOT on |+⟩|−⟩ turns the control into |−⟩, while the target stays put.

The Bernstein-Vazirani circuit

  1. Answer qubit to |−⟩ (X, then H); every input qubit to |+⟩ (H).
  2. Use the oracle once: the input register becomes Σx (−1)s·x |x⟩ / √2n.
  3. H on every input qubit again.
  4. Measure the inputs: the result is s, in every shot.
qc.x(n); qc.h(range(n + 1)); qc = qc.compose(oracle); qc.h(range(n)); qc.measure(range(n), range(n))

Why it works: signs, then interference

Module 6 · A first quantum algorithm10

The one-line reason

H on n qubits turns a basis state |s⟩ into exactly the sign pattern of s:

H⊗n |s⟩ = Σx (−1)s·x |x⟩ / √2n

The oracle produces that pattern. H is its own inverse, so H on every qubit turns the pattern back into |s⟩.

The circuit never reads the 2n values f(x) one by one: it uses one query on a superposition, and interference does the rest.

Module 6 · A first quantum algorithm11

Pause and predict

You forget the X gate, so the answer qubit starts in |+⟩ instead of |−⟩. What does the circuit return?

Always 00…0. Flipping |+⟩ does nothing at all, not even a sign, so no phase is kicked back. The inputs get H, nothing, H again, and return to |0…0⟩. The check cell in the lab catches exactly this mistake.

Deutsch-Jozsa: constant or balanced?

A promise problem: f on n bits is either

  • constant: the same answer for every x, or
  • balanced: 1 for exactly half of the inputs.

Run the same circuit once. The probability of 00…0 is

| Σx (−1)f(x) / 2n |² = 1 if constant, 0 if balanced

Module 6 · A first quantum algorithm14

What these speedups do and do not show

  • They are counted in queries to a black box, not in seconds on a real problem.
  • Bernstein-Vazirani: n queries become 1. A real gain, but it grows only in proportion to n.
  • Deutsch-Jozsa: exponential against an exact classical algorithm, small against a randomized one.
  • Simon's problem gives an exponential gap even against randomized classical algorithms, and its ideas lead to Shor's factoring algorithm. Grover's search gives a square-root speedup. Both come in the next level, Quantum Algorithms.

Pause and predict

With λ = 0.05 on every CNOT, which hidden string is found more reliably: 100000 or 111111?

100000. Its oracle has one CNOT, so only one chance for an error: about 97.5% of shots return s. The oracle for 111111 has six CNOTs: about 81%. The number of 1s in s sets the cost of the oracle on real hardware.

Summary

  • Query model: the cost is the number of questions to a black box.
  • Bernstein-Vazirani: f(x) = s·x mod 2. Classical: n queries. Quantum: 1.
  • The oracle: a CNOT to the answer qubit for each 1 in s. With the answer qubit in |−⟩, phase kickback gives (−1)s·x.
  • H, oracle, H: the signs interfere into |s⟩. The same circuit decides Deutsch-Jozsa.
  • Query speedups are real, but this one is not exponential; noise grows with the number of CNOTs.
