What a kernel does

A support vector machine (SVM) finds the boundary between two classes with the widest margin. It never needs the features themselves, only a kernel: a similarity K(x, x′) for every pair of points.

decision(x) = sign( Σᵢ αᵢ yᵢ K(xᵢ, x) + b )
  • The RBF kernel K = exp(−γ |x − x′|²) treats nearby points as similar: a round bump around each point.
  • A kernel is the inner product of the points in some feature space, which can be far larger than the data. That is the kernel trick.
  • A quantum kernel uses the 2ⁿ-dimensional state space of n qubits as the feature space.

The ZZ feature map

/*FMAP_FIG*/
  • One qubit per feature. H gates, a phase 2xᵢ on each qubit, and a CX-phase-CX block for each pair, with phase 2(π − xᵢ)(π − xⱼ).
  • The state |φ(x)⟩ depends on the data in a way that is hard to compute classically for many qubits (Havlíček et al., Nature, 2019).
  • The kernel is the overlap of two such states: K(x, x′) = |⟨φ(x)|φ(x′)⟩|², 1 when x = x′.

A fair comparison

Same data

Both models see the same 40 training points; the 20 test points are used once, at the end.

Same tuning

Both choose their settings by 4-fold cross-validation on the training points: C for both, and γ for RBF.

Honest report

Report both accuracies, the size of the test set (each point is 0.05 here) and how the data were made.

Many published "quantum advantages" in machine learning disappear when the classical model is tuned as carefully as the quantum one.

Pause and predict

The quantum kernel wins on adhoc by four test points. Is this evidence that quantum kernels classify real data better?

No. The adhoc labels were generated from the same feature map, so the result shows only that a quantum kernel can fit data with a matching quantum structure. A real claim needs real data whose structure the feature map captures, a classical baseline tuned as hard, several splits and a larger test set, and enough shots on hardware. Huang et al. (Nature Communications, 2021) showed that with enough data, classical models can often match quantum kernels.

Kernels from shots

/*OVERLAP_FIG*/
  • Run the feature map of x, then the feature map of x′ backwards. The probability of all zeros is K(x, x′).
  • With 1,000 shots each kernel value is off by about 0.01.
  • Cost: 40 training points need 40 × 39 / 2 = 780 circuits, and 20 test points 20 × 40 = 800 more: 1,580 circuits, 1.58 million shots. The capstone limit, 8 training and 4 test points, needs 28 + 32 = 60.

More qubits, smaller kernel values

/*CONC_FIG*/

50 random pairs of points per size. The mean kernel value falls like 2⁻ⁿ: /*C6*/ at 6 qubits, /*C8*/ at 8.

The spread between pairs falls as fast (/*S8*/ at 8 qubits), the 1,000-shot error only like its square root (/*E8*/).

Exponential concentration (Thanasilp et al., 2024): without a feature map designed for the data, more qubits need exponentially more shots.

Summary

  • A quantum kernel compares data through quantum states; an SVM uses it like any kernel.
  • Fair tests: same split, same tuning, test set used once. On moons the classical kernel won (/*MC*/ against /*MQ*/); on data built for the quantum kernel it lost (/*AC*/ against /*AQ*/).
  • On hardware every kernel value costs a circuit and many shots, and the number of circuits grows with the square of the data.
  • With many qubits, kernel values concentrate and shot noise wins.
