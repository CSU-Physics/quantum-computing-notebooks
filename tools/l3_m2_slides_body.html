Module 2 · Quantum error correction2

Why correct errors at all?

  • On ibm_pittsburgh (calibration of 17 April 2026) the median two-qubit gate fails about /*MED_CZ*/ times in 10,000, and the median readout /*MED_RO*/ times in 10,000.
  • A circuit with 10,000 such gates almost never runs without an error. Useful algorithms, such as Shor's for real key sizes, need billions of operations.
  • Better hardware alone will not close a gap of that size. Error correction builds reliable logical qubits out of many imperfect physical ones, and fixes errors faster than they build up.

The classical repetition code

Send each bit three times; take the majority vote. The vote is wrong only if two or three copies flip:

PL = 3p²(1 − p) + p³ = 3p² − 2p³

For p = 0.1: PL = /*PL01*/. The curves cross at p = 0.5: below it, repetition helps, and more and more as p gets smaller.

Two obstacles for qubits

  • No cloning: no circuit turns α|0⟩ + β|1⟩ into three copies (α|0⟩ + β|1⟩)⊗3 for every α and β.
  • Measurement disturbs: reading the qubits to take a vote would destroy the superposition.

The way around both:

  • entangle instead of copy: α|0⟩ + β|1⟩ → α|000⟩ + β|111⟩;
  • measure only parities: "do qubits 0 and 1 agree?" The answer depends on the error, not on α and β, so it can be measured without disturbing the stored state.

One round of the three-qubit code

/*CIRCUIT*/

Encode with two CNOTs. Each ancilla collects a parity with two CNOTs, is measured in the middle of the circuit, and is reset. The two results, the syndrome, choose the X gate through if_test: feedforward, in the same shot.

Module 2 · Quantum error correction6

The syndrome table

/*SYN_TABLE*/

s₁ = parity of qubits 0 and 1 (classical bit 0); s₂ = parity of qubits 1 and 2 (classical bit 1).

Each single flip has its own syndrome, so the code knows which qubit to fix. A counts key reads right to left: '01' means s₁ = 1, s₂ = 0.

The syndrome is the same in every shot and says nothing about α and β: the superposition survives.

Module 2 · Quantum error correction7

Feedforward in code

c = qc.clbits with qc.if_test((c[0], 1)): with qc.if_test((c[1], 1)): qc.x(1) with qc.if_test((c[1], 0)): qc.x(0) with qc.if_test((c[0], 0)): with qc.if_test((c[1], 1)): qc.x(2)

if_test((clbit, value)) runs its block only in shots where that classical bit was measured as value; qc.clbits[0] is classical bit 0. Nesting tests two bits.

This needs hardware that measures a qubit, sends the result to classical electronics and acts on it while the other qubits wait: mid-circuit measurement and dynamic circuits, available on IBM's current devices.

Module 2 · Quantum error correction8

Pause and predict

Data qubits 0 and 1 both flip. Which syndrome does the code measure, which correction does it apply, and what is left?

Qubits 0 and 1 agree again, qubits 1 and 2 do not: the syndrome is (s₁, s₂) = (0, 1), the syndrome of a single flip on qubit 2. The code applies X to qubit 2, so all three qubits are now flipped: α|111⟩ + β|000⟩, a logical X. It is a valid code state, the wrong one, and no later round can notice. The three-qubit code corrects one flip but not two: its distance is 3.

When does the code help?

/*FAIL*/

Flip probability p on each data qubit, readout error q on each syndrome bit; failure = the data are not back in the encoded state.

With perfect syndromes: 3p² − 2p³, as in the classical code. A misread syndrome makes the correction put a flip in: at p = 0.05 and q = 0.02 the round fails /*F0502*/ of the time, about as often as an unprotected qubit (0.05).

Module 2 · Quantum error correction10

Phase flips need their own code

  • A Z error turns α|000⟩ + β|111⟩ into α|000⟩ − β|111⟩. Every parity still agrees: the syndrome is 00, and the bit-flip code never sees it.
  • The phase-flip code works in the X basis: H on each qubit after encoding gives α|+++⟩ + β|−−−⟩. A Z error flips |+⟩ ↔ |−⟩, which the same parity check, done after H gates, catches.
  • Shor's nine-qubit code (1995) nests the two: three phase-flip blocks, each made of three bit-flip qubits. It corrects any error on any one qubit, because every error is a combination of I, X, Z and Y = iXZ.

Noisy gates and the break-even point

/*BREAKEVEN*/

The code's own six CNOTs are noisy too. With a 1% depolarizing error on each CNOT, the code fails /*F_SMALL*/ of the time even when the data qubits never flip.

It beats an unprotected qubit only above p ≈ /*BREAK*/, the break-even point. The operations of a code must be good enough for correction to remove more errors than it adds.

Repeated rounds and detection events

/*DEVICE*/

Three rounds of the code, 4,000 shots of logical |0⟩, with the noise of five neighbouring qubits of ibm_pittsburgh (FakePittsburgh, simulated).

A detection event is a syndrome that differs from the round before. A misread ancilla most likely gives a syndrome that appears in one round and is gone in the next; a real data flip most likely changes it and keeps it changed.

A single data qubit reads wrong /*Q_RAW*/ of the time; the majority vote of the three is wrong only /*Q_VOTE*/.

Stabilizer codes

  • The repetition code is described by the Pauli operators it measures: Z₀Z₁ and Z₁Z₂. Every code state has eigenvalue +1 for both; an error flips some of the signs, and the signs are the syndrome.
  • Codes described this way are stabilizer codes. Written [[n, k, d]]: n physical qubits, k logical qubits, distance d. As a quantum code the repetition code is [[3, 1, 1]]: a single Z error is already a logical error. Shor's code is [[9, 1, 3]].
  • The Steane code [[7, 1, 3]] measures six stabilizers on seven qubits and corrects any single-qubit error.
Module 2 · Quantum error correction14

The surface code and the threshold

/*SURFACE*/

Data qubits on a square grid, with measure qubits between them that check X or Z parities of their neighbours only. Distance d needs d² data qubits; it corrects (d − 1)/2 errors.

Threshold: if every operation fails less often than a threshold (around 1% for the surface code in common noise models; it depends on the code and the noise), each increase of d lowers the logical error rate.

Google, 2024: surface codes of distance 3, 5 and 7 on its Willow chip; the distance-7 code (101 qubits) failed 0.143% of rounds, and each step d → d + 2 cut the error rate by a factor of 2.14.

Beyond the surface code: qLDPC codes

  • The surface code needs about 2d² physical qubits for one logical qubit: hundreds or more for a useful distance.
  • qLDPC codes (low-density parity check) store several logical qubits in one block. IBM's "gross" code [[144, 12, 12]] keeps 12 logical qubits in 144 data qubits (plus 144 check qubits).
  • IBM's roadmap (June 2025): Starling, planned for 2029, with 200 logical qubits running circuits of 100 million gates. Its checks need long-range connections, which is why IBM's new chips add couplers between distant qubits.

Summary

  • A code protects a qubit by entangling it with others and measuring only parities: the syndrome locates an error without revealing the state.
  • The three-qubit code corrects one bit flip (bit-flip distance 3; as a quantum code [[3, 1, 1]]): failure 3p² − 2p³ with perfect syndromes. It cannot see phase flips; Shor's and stabilizer codes handle both.
  • Noisy syndromes and noisy gates add errors: codes need repeated rounds, and operations below a threshold.
  • Below threshold, bigger codes do better: Google's distance-7 surface code; IBM's qLDPC plans for Starling.
